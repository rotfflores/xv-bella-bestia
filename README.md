# Invitación XV años · Aitana

Invitación web estática inspirada en *La Bella y la Bestia*, lista para GitHub Pages.

## Personalización rápida

- Fecha del evento: `eventDate` en `script.js`.
- Nombre, salón, textos, mapa y WhatsApp: `index.html`.
- Música: agrega un archivo llamado `musica.mp3` dentro de `assets/`.

La publicación se realiza directamente desde la rama `main` mediante GitHub Pages.
